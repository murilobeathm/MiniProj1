# MiniProj1 — Currículo Vitae em SPA

Mini projeto de desenvolvimento web: um currículo vitae construído como **Single Page Application (SPA)**.

## Características

- **Ficheiro único** (`index.html`): HTML, CSS e JavaScript ficam todos no mesmo ficheiro e são carregados de uma só vez.
- **Navegação por links internos** (`#inicio`, `#quem-sou`, `#o-que-faco`, `#hobbies`): um pequeno router em JavaScript mostra apenas a secção ativa, sem recarregar a página. Os botões *Voltar* e *Avançar* do browser também funcionam.
- **Secções:** Início, Quem Sou Eu?, O que faço?, Hobbies.
- **Janelas modais:** formulário de contacto e detalhes de cada hobby.
- **Rodapé com identidade virtual:** ícones de Facebook, X (Twitter), LinkedIn, GitHub, Instagram e YouTube, visível em todas as secções.
- Design responsivo (menu móvel) e tema claro/escuro.

## Como abrir

Abrir o ficheiro `index.html` diretamente no browser (não precisa de servidor).
